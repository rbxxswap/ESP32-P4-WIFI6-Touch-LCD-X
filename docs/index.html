Before you start

  1. Use a Chromium-based desktop browser (Chrome, Edge, Opera). Firefox, Safari and all mobile browsers lack the Web Serial API and cannot flash.
  2. Connect the board with a USB-C data cable (not charge-only).
  3. Click Connect, pick the board's serial port, then follow the prompts.
  4. On first install, choose Erase device when offered.

What gets flashed

A single merged image (firmware-merged-esp32p4.bin, ~3.7 MB) at offset 0x0 — bootloader, partition table and application combined.

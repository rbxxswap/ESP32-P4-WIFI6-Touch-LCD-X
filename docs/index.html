ESP32-P4-WIFI6-Touch-LCD-X Web Flasher

Smart Display firmware — flash directly from your browser, no local tools required.

Your browser is not supported. Use Chrome, Edge or Opera on desktop. This page must be served over HTTPS to flash.

Version v0.1.0-alpha.1 · pre-release

Before you start

  1. Use a Chromium-based desktop browser (Chrome, Edge, Opera). Firefox, Safari and all mobile browsers lack the Web Serial API and cannot flash.
  2. Connect the board to your computer with a USB-C data cable (not charge-only).
  3. Click Connect, pick the serial port for the board, then follow the prompts.
  4. On first install, choose Erase device when offered — this writes a clean image.
Pre-release / alpha. This is an early build for testing the display, touch, launcher and Wi-Fi setup. Expect rough edges. Flashing replaces any firmware currently on the device.

What gets flashed

A single merged image (firmware-merged-esp32p4.bin, ~3.7 MB) written at offset 0x0 — it contains the bootloader, partition table and application.
